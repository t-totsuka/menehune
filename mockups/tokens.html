色（役割と意味）

部品と画面は、役割の色（--color-*）だけを参照します。祝日、六曜、天文現象、投稿の状態などの意味を持つ色も、役割の名前で定義しています。各セルの背景は、そのテーマの --color-bg です。

使用例

同じ部品を、ライトとダークの値で並べています。意味は色だけでなく文字でも示します。

コントラスト比

検査ツール（tools/contrast-pairs.json、npm run check:contrast）と同じ組み合わせについて、両テーマのコントラスト比を示します。本文の組の基準は 4.5:1、大きな文字・アイコン・境界線・フォーカスの組の基準は 3:1 です。

素材の色

素材の色（--palette-*）は、役割の色の値の元です。部品は素材の色を直接参照しません。見本は、ライトとダークの背景の上に置いています。

使用例

役割の色は、テーマごとに素材の色を参照します。表の「参照している役割」の列に、その素材の色を使う役割を示しています。

:root { --color-accent: var(--palette-indigo-700); }
:root[data-theme="dark"] { --color-accent: var(--palette-gold-300); }
.button { background-color: var(--color-accent); }

ブレークポイント

CSS の変数は @media に使えないので、@media には同じ数値を書きます（npm run check:tokens が一致を検査します）。

使用例

  • 600px 未満：ヘッダーがメニューボタンに、月のカレンダーが小さな格子と要約パネルに切り替わり、コメントの字下げが 3 段までになる
  • 600px 以上：ページの左右の余白が --space-lg になる
  • 960px 以上：見出しが大きくなり、投稿詳細の位置パネルなどが横並びになる
  • 1280px：ページの本文の最大幅（.l-container）
@media (width < 600px) { … }
@media (min-width: 960px) { … }
.l-container { max-width: var(--bp-lg); }
